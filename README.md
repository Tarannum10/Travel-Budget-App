# 🌍 Travel Budget App 💰

A fullstack MERN application to track and manage travel expenses with beautiful UI and real-time budget monitoring.

## ✨ Features

- ✈️ **Multi-Trip Management** - Track multiple trips simultaneously
- 💵 **Budget Tracking** - Real-time budget monitoring with visual progress bars
- 📊 **Category-wise Analysis** - 6 expense categories (Transport, Accommodation, Food, Shopping, Activities, Other)
- 🎨 **Beautiful UI** - Modern gradient design with smooth animations
- 🔔 **Smart Alerts** - Budget overspending notifications
- 💱 **Multi-Currency** - Support for USD, EUR, GBP, INR, JPY
- 📱 **Responsive Design** - Works perfectly on all devices

## 🛠️ Tech Stack

### Frontend
- ⚛️ **React** - UI library
- ⚡ **Vite** - Build tool
- 🎨 **Tailwind CSS** - Styling
- 🎯 **Lucide React** - Icons

### Backend (Coming Soon)
- 🟢 **Node.js** + Express
- 🍃 **MongoDB** - Database
- 🔐 **JWT** - Authentication

## 💻 Installation

### Prerequisites
- Node.js 16+ installed
- npm or yarn

### Steps
```bash
# Clone the repository
git clone https://github.com/Tarannum10/Travel-Budget-App.git

# Navigate to project directory
cd Travel-Budget-App/travel-budget-app

# Install dependencies
npm install

# Run development server
npm run dev
```

The app will open at `http://localhost:5173`

## 📦 Build for Production
```bash
npm run build
```

## 🎯 Usage

1. **Create a Trip** - Click "New Trip" and enter destination, dates, and budget
2. **Add Expenses** - Click "Add Expense" to log your spending
3. **Track Budget** - Monitor your spending with real-time stats
4. **Analyze Categories** - See spending breakdown by category
