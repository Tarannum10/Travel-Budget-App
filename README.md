# ✈️ Travel Budget App

## ✨ Features

- **Budget Planning:** Set an overall budget for your trip.
- **Expense Tracking:** Add individual expenses with categories (e.g., Food, Accommodation, Transport).
- **Real-time Calculation:** Instantly see your remaining budget as you add expenses.
- **Data Persistence:** Your budget and expenses are saved in your browser's local storage.
- **Responsive Design:** Works seamlessly on desktop, tablet, and mobile devices.
- **Zero Setup:** Fully client-side; no backend or database required.

## 🛠️ Built With

- **HTML5:** For the structure and semantic layout.
- **CSS3:** For modern styling, flexbox/grid layout, and responsiveness.
- **Vanilla JavaScript (ES6+):** For all the application logic and dynamic interactions.

## 📦 Installation & Local Development

Want to run this project locally? Follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/your-username/Travel-Budget-App.git
    ```
2.  **Navigate to the project directory:**
    ```bash
    cd Travel-Budget-App
    ```
3.  **Open the `index.html` file in your browser:**
    You can simply double-click the `index.html` file, or use a local server for a better experience.

    *Using a local server with Live Server (VSCode extension) or Python:*
    ```bash
    # Python 3
    python -m http.server 8000
    ```
    Then, visit `http://localhost:8000` in your browser.

## 🎯 How to Use

1.  Open the app.
2.  Enter your total trip budget and click "Set Budget".
3.  Add expenses by providing a name, amount, and category.
4.  Watch your remaining budget update automatically.
5.  Your data is saved automatically in your browser.
